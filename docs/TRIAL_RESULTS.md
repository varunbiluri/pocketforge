# Independent trial evidence

No independent trials have been collected. Internal examples and BANKING77 experiments are engineering evidence, not adoption evidence.

Use the [trial kit](TRIAL_KIT.md) with consenting developers. Record an anonymized trial ID, package version/commit, date, platform, task type, dataset counts, and consent to share aggregate findings. Do not commit source data, model files, names, contact details, or private issue links.

For each trial, record:

- Quality, latency and operational acceptance criteria fixed before test evaluation.
- Time to first prediction, installation failures, undocumented steps, and issue links with synthetic reproductions.
- Baseline/current-system comparison on identical held-out cases, hardware and timing protocol; cost assumptions separately from measurements.
- Outcome: completed workflow, integrated model, repeat use, or declined adoption, with the reason. A result favoring the existing system is valid.
- Follow-up fixes and their verification on the affected platform/version.
