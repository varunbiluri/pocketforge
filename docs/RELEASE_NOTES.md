# PocketForge 0.1.0a5 — alpha UX polish

Version 0.1.0a5 improves first-run onboarding after the 10-scenario alpha test pass. It adds `pocketforge init` to create a starter task, makes malformed task YAML errors explain found/missing/unexpected keys, and documents harmless `uv` dependency-scan warnings during install.

Install from PyPI with `python -m pip install pocketforge==0.1.0a5`, install the wheel from the matching GitHub release, or clone the repository and use the lockfile. Independent user trials, integrations, and market validation remain pending; use docs/TRIAL_KIT.md to participate.
