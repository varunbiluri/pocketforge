# PocketForge 0.1.0a6 — starter and batch prediction polish

Version 0.1.0a6 extends the alpha workflow after the roadmap issue pass. `pocketforge init` now supports custom task names, custom comma-separated labels, CSV or JSONL starter files, and a generated folder README. `pocketforge predict` now accepts CSV/JSONL batch input with a `text` field and can write predictions to JSON.

Install from PyPI with `python -m pip install pocketforge==0.1.0a6`, install the wheel from the matching GitHub release, or clone the repository and use the lockfile. Independent user trials, integrations, and market validation remain pending; use docs/TRIAL_KIT.md to participate.
